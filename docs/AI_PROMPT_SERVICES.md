# Промпт для преобразования прайс-листа в JSON

Используйте этот промпт в ChatGPT, Claude или другом AI для преобразования фото или текста прайс-листа в JSON формат для импорта.

## Промпт

```
Преобразуй этот прайс-лист в JSON для импорта услуг. Формат:

{
  "services": [
    {
      "name": "Название услуги",
      "description": "Описание (если есть)",
      "category": "Категория",
      "subcategory": "Подкатегория (опционально, напр. Женские/Мужские)",
      "hall": "Зал (опционально, если указан в прайсе)",
      "duration_minutes": 60,
      "price": 2500
    }
  ],
  "defaults": {
    "duration_minutes": 30,
    "price": 0,
    "category": "Без категории"
  }
}

Правила:
1. name - обязательное поле, оставь как в оригинале
2. price - цена в рублях (целое число, без копеек). Если нет цены - поставь 0
3. duration_minutes - примерная длительность процедуры. Если не указана - поставь 30
4. category - группируй услуги по категориям из прайса
5. subcategory - если есть разделение внутри категории (Женские/Мужские, Короткие/Длинные волосы), добавь
6. hall - если услуги разделены по залам/кабинетам, укажи
7. description - краткое описание, если есть
8. Цены "от 500" - указывай минимальную цену: 500
9. Все числа без пробелов и знаков валюты

Выдай ТОЛЬКО JSON, без дополнительного текста.

Прайс-лист:
[ВСТАВЬТЕ ФОТО ИЛИ ТЕКСТ ПРАЙС-ЛИСТА]
```

## Использование

1. Скопируйте промпт выше
2. Вставьте фото прайс-листа или текст в конец
3. Отправьте в ChatGPT/Claude
4. Сохраните результат в файл `services.json`
5. Импортируйте:

```bash
# На сервере:
./scripts/import_services.sh beautysalon services.json

# Или через curl:
curl -X POST https://api-domain.com/api/import/services \
     -H "Content-Type: application/json" \
     -d @services.json
```
